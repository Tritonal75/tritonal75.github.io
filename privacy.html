Privacy Policy

Daffodil Gmail Automation · last updated 5 September 2026

Summary

Daffodil Gmail Automation is a personal command-line tool with a single user: its author. It runs on his own computer and accesses only his own Gmail account. It has no servers, no other users, and no third parties. No data leaves the machine it runs on except in the ordinary course of talking to Google's own Gmail API.

What data is accessed

When the user runs a command, the tool may read messages, message metadata and attachments from his own Gmail mailbox, create drafts in it, and send mail from it. It accesses this data only while a command is running, and only in response to the user starting that command. Nothing runs on a schedule against anyone else's account, because there is no other account.

What data is stored

  • OAuth tokens, in a private directory on the user's own machine, readable only by his operating system account. They exist so that he does not have to sign in on every command.
  • Attachments, only when he explicitly asks for one to be downloaded, and only to the folder he names.

Message contents are not written to disk, not cached, and not retained after a command finishes.

What data is shared

None. There is no server, no database, no analytics, no telemetry, no logging service, and no advertising. Data is never sold, transferred or disclosed to anyone. The only network connections the tool makes are to Google's own endpoints, to do what the user asked.

Google API Services User Data Policy

This tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Stored tokens can be deleted at any time by removing the tool's configuration directory, which immediately ends its access. Access can also be revoked independently at myaccount.google.com/permissions, which invalidates the tokens whether or not the files are deleted.
