Daffodil Gmail Automation

A personal command-line tool for one person's own Gmail account.

What it is

A set of small command-line utilities that let their author work with his own Gmail account from a personal Linux machine: searching mail, downloading attachments, preparing drafts, and sending messages to a short, fixed list of recipients.

It is not a product and not a service. There is one user, it runs on one machine, and it has no web interface, no hosting, and no other users.

What it accesses

  • gmail.readonly — reading messages, to search mail and fetch attachments
  • gmail.compose — creating drafts for review before they are sent
  • gmail.send — sending, restricted to an allowlist of addresses

All access is to the account of the person who installed it. The tool cannot reach any other account.

Where it runs

On a single personal computer. Credentials are stored in a private directory on that machine. Nothing is uploaded, hosted, or shared with anyone.
