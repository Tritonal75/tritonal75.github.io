# daffodil-gmail-automation

The public homepage and privacy policy for **Daffodil Gmail Automation**, a
personal command-line tool for one person's own Gmail account.

These two pages exist because Google's OAuth consent screen requires a homepage
and a privacy policy URL before an app can be published. They are hosted with
GitHub Pages:

- <https://tritonal75.github.io/daffodil-gmail-automation/>
- <https://tritonal75.github.io/daffodil-gmail-automation/privacy.html>

This repository contains nothing else. The tool itself is private.
